# **App Name**: DailyFlow

## Core Features:

- タスク新規作成: 新しいタスクをタイトル、説明、期日、初期ステータスと共に作成します。
- タスク一覧表示: 作成されたすべてのタスクを一覧形式で表示し、ステータスや期日などでフィルタリングできる機能を提供します。
- タスク進捗更新: 各タスクのステータス（例：未着手、進行中、完了）を簡単に更新します。
- タスク詳細編集: 既存のタスクのタイトル、説明、期日などの詳細情報を編集および保存します。
- タスクデータの永続化: 作成・更新されたすべてのタスクデータをデータベースに保存し、取得できるようにします。
- AIによるタスク説明補助: 簡潔なタスクの説明から、AIツールがより詳細な説明や関連するサブタスクの提案を行います。

## Style Guidelines:

- 主色: 主要なテキストやUI要素に使用する深いグレー/ブルートーンです。専門性と落ち着きを表現します。（#2F333A）
- 背景色: クリーンで明るい、非常に薄いグレー/ブルートーンで、主要なコンテンツ領域の背景に適しています。（#F9FAFC）
- アクセント色: '緑'のリクエストに基づき、アクティブな状態、重要なアクション、進捗を示すために使用される鮮やかなグリーンです。（#2DAF5A）
- 本文および見出しフォント: 'Inter'（サンセリフ体）を使用し、モダンで読みやすく、クリーンな外観を提供します。
- システムアイコン: シンプルで分かりやすいラインアイコンを使用し、タスクの追加、編集、完了などの主要な操作を視覚的に表現します。
- クリーンで整理されたレイアウトを特徴とし、タスクリスト、詳細ビュー、フォームは直感的で操作しやすい配置にします。応答性の高いデザインを採用します。
- タスクのステータス変更、新規タスクの追加、またはリストのフィルタリング時など、UI要素間のスムーズで控えめなトランジション（移行）を追加し、ユーザーエクスペリエンスを向上させます。
