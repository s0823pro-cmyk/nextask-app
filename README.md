# DailyFlow - 業務効率化タスク管理プラットフォーム

DailyFlowをご利用いただきありがとうございます。このプロジェクトを安定して運用するためのメンテナンスガイドです。

## 定期メンテナンスのポイント

### 1. データのクリーンアップ
完了済みのタスクが蓄積されると、読み込み速度に影響する場合があります。
- 半年〜1年以上経過した「完了」タスクの削除またはアーカイブ。
- 不要になった取引先（Client）の削除。

### 2. Firebase コンソールの監視
Firebaseコンソール（https://console.firebase.google.com/）にて、以下の項目を定期的に確認してください。
- **Firestore Usage**: 無料枠（1日5万読み取り、2万書き込み）を超えていないか。
- **Authentication**: 意図しないユーザーが登録されていないか。

### 3. セキュリティ設定の強化
現在はプロトタイプ用の設定になっています。本番運用では以下の検討を推奨します。
- `firestore.rules` の修正（管理者メールアドレスによる厳格な制限など）。
- 匿名認証以外の認証方法（Googleログイン等）への移行。

### 4. PDFストレージの注意
本アプリではPDFをBase64形式でデータベースに直接保存しています。
- 1つのタスクに大きなPDFを多数添付すると、データの読み込みが重くなる原因となります。
- 1ファイル数MB程度の運用を推奨します。
