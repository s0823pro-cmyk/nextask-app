## ⚠️ 初回ログイン時の注意（重要）
もしログインボタンでエラーが出る場合は、以下の設定を確認してください。

1.  **Googleログインを有効にする**: 
    Firebaseコンソールの [Authentication] -> [Sign-in method] で「Google」が有効になっているか確認してください。
2.  **承認済みドメインを追加する**:
    同じ画面の下部にある「承認済みドメイン」に、現在表示しているサイトのドメイン（例: `xxxx.web.app`）が追加されているか確認してください。
3.  **ポップアップを許可する**:
    ブラウザがログイン画面をブロックしている場合、アドレスバーの右側にあるアイコンをクリックして許可してください。
