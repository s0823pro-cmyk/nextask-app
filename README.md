
# NexTask - 業務効率化タスク管理プラットフォーム

NexTaskをご利用いただきありがとうございます。このプロジェクトを安定して運用するためのメンテナンスガイドです。

## セキュリティとプライバシーについて

### 共有URLの安全性
- **取引先ごとの完全分離**: 各取引先には、ランダムに生成された専用の識別子（12桁の英数字）が割り振られます。
- **データ漏洩の防止**: `/view/[識別子]` という形式のURLは、その識別子に紐付いたタスクのみを表示します。他の取引先のタスクが混ざったり、別の業者が他社のタスクを閲覧することはできません。
- **URLの推測防止**: 識別子はランダムであるため、URLを適当に入力して他社のページに辿り着くことは極めて困難です。

## 定期メンテナンスのポイント

### 1. データのクリーンアップ
完了済みのタスクが蓄積されると、読み込み速度に影響する場合があります。
- 半年〜1年以上経過した「完了」タスクの削除またはアーカイブ。
- 不要になった取引先（Client）の削除。

### 2. Firebase 無料枠（Sparkプラン）の目安
Firebaseの無料枠は非常に強力ですが、以下の制限を意識してください。
- **Firestore 読み取り**: 1日 50,000回まで。
- **Firestore 書き込み**: 1日 20,000回まで。
- **保存容量**: 合計 1GBまで。
- **ドキュメントサイズ上限**: 1つのタスクにつき **1MB** まで。
  - ※PDFをBase64で保存しているため、大きなファイル（1MB超）を添付するとエラーになる、または容量を早く消費します。

### 3. 読み取りカウントとコストについて
Firestoreの料金（読み取り回数）は、**「画面に表示されているか」ではなく「データベースから何件取り出したか」**で決まります。
- **UIフィルタの注意**: 検索窓でタスクを絞り込んでいる際、画面から消えているタスクも、プログラムが一度読み込んでいれば1回としてカウントされます。
- **共有先URLの注意**: 取引先が共有URL（ポータル画面）にアクセスしてタスクを確認した際も、読み取り回数としてカウントされます。

### 4. 従量課金（Blazeプラン）の目安と2,000円を超える規模
月額2,000円程度のコストが発生するのは、以下のような「大規模運用」になった場合です。

**コストシミュレーション（目安）:**
- **月間2,000万回以上の読み取り**: 数百の取引先が、毎日何度も進捗を確認する規模。
- **約70GB以上のデータ保持**: PDF付きタスクが数万件規模で蓄積された状態。
- **約100GB以上の転送量**: 共有URLから大量の資料が頻繁にダウンロードされる状態。

**通常のビジネス利用（取引先数十社程度）であれば、無料枠内〜月額数百円程度で収まることがほとんどです。**

### 5. 安心運用のための設定
- Firebaseコンソールで「予算アラート」を設定してください（例：月500円を超えたら通知）。これにより、意図しない高額請求を防げます。
- 本格運用の場合、PDFは Base64形式ではなく Firebase Storage への移行を検討することで、さらにコスト効率と安定性が向上します。
