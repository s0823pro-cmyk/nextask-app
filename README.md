# DailyFlow - 業務効率化タスク管理プラットフォーム

DailyFlowをご利用いただきありがとうございます。このプロジェクトを安定して運用するためのメンテナンスガイドです。

## 定期メンテナンスのポイント

### 1. データのクリーンアップ
完了済みのタスクが蓄積されると、読み込み速度に影響する場合があります。
- 半年〜1年以上経過した「完了」タスクの削除またはアーカイブ。
- 不要になった取引先（Client）の削除。

### 2. Firebase 無料枠（Sparkプラン）の目安
Firebaseの無料枠は非常に強力ですが、以下の制限を意識してください。
- **Firestore 読み取り**: 1日 50,000回まで。
- **Firestore 書き込み**: 1日 20,000回まで。
- **保存容量**: 合計 1GBまで。
- **ドキュメントサイズ上限**: 1つのタスクにつき **1MB** まで。
  - ※PDFをBase64で保存しているため、大きなファイル（1MB超）を添付するとエラーになる、または容量を早く消費します。

### 3. 読み取りカウントとコストについて
Firestoreの料金（読み取り回数）は、**「画面に表示されているか」ではなく「データベースから何件取り出したか」**で決まります。
- **UIフィルタの注意**: 検索窓でタスクを絞り込んでいる際、画面から消えているタスクも、プログラムが一度読み込んでいれば1回としてカウントされます。
- **最適化のヒント**: データ件数が非常に多くなった場合は、すべてのデータを読み込むのではなく、「未完了のタスクのみ読み込む」といったサーバー側での絞り込み（クエリ）を強化することで、コストを大幅に抑えることができます。

### 4. 従量課金（Blazeプラン）への移行と料金
無料枠（1GB）を超えそうになった場合、Google Cloud 請求先アカウントを紐付けて「Blazeプラン」に切り替えることで継続利用が可能です。

**料金の目安（2025年時点）:**
- **読み取り**: 10万回ごとに約9円 ($0.06)
- **書き込み**: 10万回ごとに約27円 ($0.18)
- **保存容量**: 1GBあたり月額 約27円 ($0.18)
- **ネットワーク転送**: 1GBあたり 約18円 ($0.12)

**安心運用のための推奨設定:**
- Firebaseコンソールで「予算アラート」を設定してください（例：月500円を超えたら通知）。これにより、意図しない高額請求を防げます。

### 5. Firebase コンソールの監視
Firebaseコンソール（https://console.firebase.google.com/）にて、以下の項目を定期的に確認してください。
- **Firestore Usage**: グラフで現在の利用量を確認できます。
- **Authentication**: 意図しないユーザーが登録されていないか。

### 6. セキュリティ設定の強化
現在はプロトタイプ用の設定になっています。本番運用では以下の検討を推奨します。
- `firestore.rules` の修正（管理者メールアドレスによる厳格な制限など）。
- 匿名認証以外の認証方法（Googleログイン等）への移行。

### 7. PDFストレージの注意
本アプリではPDFをBase64形式でデータベースに直接保存しています。
- **ファイルサイズの抑制**: 1つのPDFは数百KB程度に抑える運用を推奨します。
- **本格運用の場合**: 将来的には Firebase Storage への移行を検討してください（現在はシンプルさを優先しています）。
