# NexTask - 本番公開（デプロイ）完全ガイド

NexTaskを世界中に公開し、友人が401エラーなしで閲覧できるようにするための手順書です。

## ✅ ステップ1: GitHub への送信（成功！）

GitHubのリポジトリにファイルが並んでいれば、このステップは完了です。

## 🚀 ステップ2: Firebase App Hosting の設定

GitHubへの送信が成功したら、以下の設定でFirebaseを動かします。

1. [Firebase Console](https://console.firebase.google.com/) > **「App Hosting」** を選択。
2. GitHub リポジトリ（`nextask-app`）を選択。
3. **ブランチ名**: `main` を選択。
4. **デプロイ設定**:
   - **デプロイID**: デフォルトのままでOK
   - **アプリのルートディレクトリ**: 空欄（または `/`）のまま
5. **Firebase ウェブアプリの関連付け**:
   - **「新しいウェブアプリを作成」** を選択。
   - 名前を `nextask-web` などにして登録。
6. 「デプロイ」を実行。

## 💡 トラブルシューティング

### 「ブランチ名が無効」と出る場合
- 画面をリロード（更新）してください。GitHubに `main` ブランチが作成された直後は、Firebase側がまだそれを認識できていないことがあります。一度戻って選び直すと解決します。

### GitHubへの送信がうまくいかない場合（最終手段）
ターミナルで以下のコマンドを実行してください（`[トークン]` は作成した `ghp_...` に書き換えてください）。

```bash
git remote set-url origin https://[トークン]@github.com/s0823pro-cmyk/nextask-app.git
git push -u origin main
```

## 💰 料金と「予算額」について
Firebase App Hosting を利用するには、Firebase プロジェクトを **「Blaze プラン（従量制）」** にアップグレードする必要があります。

- **無料枠があります**: 小規模な利用であれば、多くの場合 **実質 0 円** で運用可能です。
- **予算額**: 1,000円 程度に設定するのが安心です。
