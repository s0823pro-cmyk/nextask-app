## 🚀 サイトを更新して本番に反映する
変更を保存してサイトに反映させたい時は、以下のコマンドをターミナルに貼り付けてエンターキーを押してください。

```bash
git add . && git commit -m "site update" && git push origin main
```
※ パスワードを聞かれたら、保存してある「トークン（ghp_...）」を貼り付けてください。

## 🔗 取引先に共有する際の注意（URLの選び方）
開発画面（Google Cloud Workstations）のURLをそのまま送ると、相手には「401エラー（権限なし）」が表示されます。

### 正しい共有手順
1.  **Firebaseコンソール**を開く。
2.  **App Hosting** のメニューから、あなたのアプリの「ドメイン（URL）」を確認します（例: `https://xxxx.web.app`）。
3.  その**公開URL**をブラウザで開き、画面内の「共有URLをコピー」ボタンを使ってリンクを取得してください。
