# NexTask - 業務効率化タスク管理プラットフォーム

NexTaskをご利用いただきありがとうございます。このプロジェクトを本番環境に公開し、安定して運用するためのガイドです。

## 🚀 本番環境への公開（デプロイ）手順

現在表示されているURL（`workstations.cloud.google.com`）は開発専用のプライベート環境です。友人に共有するには、以下の手順で「本番公開」が必要です。

### 1. 公開作業の開始
1. Firebaseコンソールの左メニューから **「App Hosting」** を選択。
2. **「開始」** をクリックし、GitHubリポジトリと接続します。
3. デプロイが完了すると、`https://your-app-name.web.app` のような **本番用URL** が発行されます。
4. **友人に共有するのは、この「本番用URL」です。**

### 2. 認証機能の設定（デプロイ後に必ず確認）
アプリを正しく動作させるために、Firebaseコンソールの **Authentication > Sign-in method** で以下の設定が「有効」であることを確認してください。
- **匿名 (Anonymous)**: 有効（共有URLの閲覧に必要）
- **Google**: 有効（管理画面へのログインに必要）

---

## ⚠️ 共有時の注意点（401エラーについて）

### なぜ友人が開けないのか？
開発環境のURLは、Google Cloudの強力なセキュリティによって保護されています。
- **開発用URL**: あなたのブラウザでしか開きません（401エラーは正常な動作です）。
- **本番用URL**: デプロイ後に発行されるURL。これは世界中からアクセス可能です。

### 自分のスマホで確認したい場合
1. スマホのブラウザで、**開発環境と同じGoogleアカウント**にログイン。
2. その状態で開発用URLを開く。
（※本番デプロイ後は、ログインなしで誰でも本番用URLを開けるようになります）

## 🛠 メンテナンスのポイント

### セキュリティルールについて
- 取引先ごとのデータは `/client_task_views/{identifier}` を通じて、その識別子を知っている人だけが閲覧できる仕組みになっています。
- 管理者（あなた）が書き込むデータは、Firebase Authによって保護されています。

### データのクリーンアップ
- 完了済みのタスクが増えてきたら、定期的に削除することで動作が軽快になります。
