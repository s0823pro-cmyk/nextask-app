
# NexTask - 業務効率化タスク管理プラットフォーム

NexTaskをご利用いただきありがとうございます。このプロジェクトを安定して運用するためのメンテナンス・セットアップガイドです。

## 初期セットアップ（重要）

アプリを正しく動作させるために、以下の設定を必ずFirebaseコンソールで行ってください。

### 1. 認証機能（Authentication）の有効化
1. [Firebase Console](https://console.firebase.google.com/) でプロジェクトを選択。
2. 左メニューから **Authentication** を選択。
3. **Sign-in method** タブをクリック。
4. **「新しいプロバイダを追加」** から以下の2つを有効にします：
   - **匿名 (Anonymous)**: 有効にして保存。 (共有URLの閲覧に必要)
   - **Google**: 有効にして、サポートメールを選択して保存。 (管理画面へのログインに必要)

## 共有とアクセス制限について（重要：401エラーが出る場合）

### 1. 開発環境のURL制限（401 Unauthorized）
現在、ブラウザに表示されているURL（`workstations.cloud.google.com` を含むもの）は、**開発用の一時的なプライベート環境**です。
- **自分だけが見れる**: あなたが自分のGoogleアカウントでログインしているブラウザでのみ開けます。
- **友人が開けない理由**: 友人がそのURLを開こうとすると、Google Cloudのセキュリティ（401エラー）によってブロックされます。これはアプリの不具合ではなく、開発環境を守るためのGoogle Cloudの仕様です。

### 2. 友人に共有・公開する方法
友人にアプリを見せるためには、アプリを「本番環境（Firebase App Hosting）」に**デプロイ（公開）**する必要があります。
デプロイが完了すると、`https://your-app-name.web.app` のような、世界中からアクセス可能なURLが発行されます。そのURLを共有することで、友人も閲覧できるようになります。

### 3. 自分のスマホで確認する方法
自分のスマホで動作確認をしたい場合は、スマホのブラウザでも**開発環境と同じGoogleアカウント**でGoogleにログインした状態でURLを開いてください。

## セキュリティとプライバシーについて

### 共有URLの安全性
- **取引先ごとの完全分離**: 各取引先には、ランダムに生成された専用の識別子（12桁の英数字）が割り振られます。
- **データ漏洩の防止**: `/view/[識別子]` という形式のURLは、その識別子に紐付いたタスクのみを表示します。
- **URLの推測防止**: 識別子はランダムであるため、他社のページに辿り着くことは困難です。

## 定期メンテナンスのポイント

### 1. データのクリーンアップ
完了済みのタスクが蓄積されると、読み込み速度に影響する場合があります。
- 不要になったタスクの削除。

### 2. Firebase 無料枠（Sparkプラン）の目安
- **Firestore 読み取り**: 1日 50,000回まで。
- **Firestore 書き込み**: 1日 20,000回まで。
- **保存容量**: 合計 1GBまで。
