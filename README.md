## 🚀 サイトを爆速で更新する（自動化の代わり）
変更を保存してサイトに反映させたい時は、以下のコマンドを**コピーしてターミナルに貼り付け、エンターキーを押すだけ**で完了します。

```bash
git add . && git commit -m "site update" && git push origin main
```
※ パスワードを聞かれたら、保存してある **「トークン（ghp_...）」** を貼り付けてください。

## ⚠️ 「安全ではないサイト」と表示される場合
新しいURLはブラウザの自動判定で一時的に警告が出ることがあります。以下の手順で解除できます。

### 解除手順（Microsoft Edgeの場合）
1. 警告画面の **「詳細情報」** をクリック。
2. **「このサイトには脅威が含まれていないことを報告する」** をクリック。
3. Microsoftのページが開くので、「このサイトは安全である」として送信してください。

### なぜ警告が出るの？
作られたばかりのURLには一律で警告が出る仕組みになっています。数日間運用し、数人が「安全」として報告すれば、自然と警告は出なくなります。
