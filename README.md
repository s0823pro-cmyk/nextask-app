## ⚠️ 「安全ではないサイト」と表示される場合
新しいURLはブラウザ（EdgeやChrome）の自動判定で一時的に警告が出ることがあります。以下の手順で解除できます。

### 解除手順（Microsoft Edgeの場合）
1. 警告画面の **「詳細情報」** をクリック。
2. **「このサイトには脅威が含まれていないことを報告する」** をクリック。
3. Microsoftのページが開くので、「このサイトは安全である」として送信してください。
4. 送信後、または警告画面で **「このサイトを続行する（推奨されません）」** をクリックすれば閲覧可能です。

### なぜ警告が出るの？
フィッシング詐欺対策として、作られたばかりのURLやアクセス数が少ないURLには一律で警告が出る仕組みになっています。数日間運用し、数人が「安全」として報告すれば、自然と警告は出なくなります。

## ✅ 最新版をデプロイする手順（更新の反映）

プログラムを変更したら、以下の3つのコマンドをターミナルで順番に実行してください。

### 1. 変更を保存する
```bash
git add .
git commit -m "update layout and features"
```

### 2. GitHubに送信する
```bash
git push origin main
```
※ パスワードを求められたら、作成した **「トークン（ghp_...）」** を貼り付けてください。

### 3. Firebaseで確認する
- [Firebase コンソール](https://console.firebase.google.com/)を開く。
- 「App Hosting」のタブを開き、ビルド（構築）が開始されているのを確認。
- 「成功」になったら、URLを開いて確認してください。

## 🛠️ トラブルシューティング
- **GitHubへの送信でエラーが出る**: 
  トークンの期限が切れていないか確認してください。
- **ビルドが失敗する**: 
  Firebase コンソールの「ログ」タブを見ると、エラーの内容が詳しく表示されます。
