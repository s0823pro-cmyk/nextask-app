# NexTask - 本番公開（デプロイ）完全ガイド

NexTaskを世界中に公開し、友人が401エラーなしで閲覧できるようにするための手順書です。

## ✅ ステップ1: GitHub への送信（成功済み）

GitHubのリポジトリにファイルが並んでいれば、このステップは完了です！

## 🚀 ステップ2: Firebase App Hosting の設定

GitHubへの送信が成功したら、以下の設定でFirebaseを動かします。

1. [Firebase Console](https://console.firebase.google.com/) > **「App Hosting」** を選択。
2. GitHub リポジトリ（`nextask-app`）を選択。
3. **「ブランチ名が無効」と出る場合の対処法**:
   - **画面をリロード**: ブラウザの更新ボタンを押して、設定を最初からやり直してください。
   - **戻って進む**: 一度リポジトリ選択まで戻り、再度選び直すと `main` が選択肢に出現します。
   - **直接入力**: 選択肢に出ない場合は `main` と入力してEnterを押してください。
4. **その他の設定**:
   - **デプロイID**: 任意（デフォルトのままでOK）
   - **アプリのルートディレクトリ**: 空欄（デフォルト）のまま
   - **ライブブランチ**: `main`
5. 「デプロイ」を実行。

## 💰 料金と「予算額」について
Firebase App Hosting を利用するには、Firebase プロジェクトを **「Blaze プラン（従量制）」** にアップグレードする必要があります。

- **無料枠があります**: 小規模な利用であれば、多くの場合 **実質 0 円** で運用可能です。
- **予算額**: 1,000円 程度に設定するのが安心です。
