## ⚠️ ログインエラーの解決方法
ログイン時にエラーが出る場合は、以下の手順を一度だけ行う必要があります。

### 1. 承認済みドメインの追加（重要）
ログイン失敗時に「ドメインが許可されていません」と表示される場合：
1. [Firebase コンソール](https://console.firebase.google.com/)を開きます。
2. 左メニューの **[Authentication]** をクリックします。
3. 上部タブの **[設定]** をクリックします。
4. 左側の **[承認済みドメイン]** を選択します。
5. **[ドメインの追加]** ボタンを押し、現在表示しているサイトのドメイン（例: `xxxx.web.app`）を入力して保存します。

### 2. Googleログインの有効化
1. Firebaseコンソールの **[Authentication]** > **[Sign-in method]** を開きます。
2. **[新しいプロバイダを追加]** で「Google」を選択し、有効にして保存してください。
